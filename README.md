# TripTrail ✈️

TripTrail is a responsive travel website front end built with pure HTML and CSS. It lets visitors explore destinations, compare tour packages, read travel articles, and fill in a trip booking request.

## Pages
- **Home**: hero section with a trip search box, popular destinations, reviews
- **Destinations**: destination cards with best time to visit
- **Packages**: Budget, Standard and Premium plans
- **Blog**: travel guides and a newsletter signup
- **Booking**: traveller and trip details form
- **Contact**: contact form and FAQ
- **Login / Register**: account forms with a bubble background

## Features
- Fully responsive layout (desktop, tablet, mobile)
- Card layouts with hover effects and shadows
- Consistent blue colour theme
- Clean, semantic HTML with accessible form labels

## Built with
- HTML5
- CSS3 (Flexbox and Grid)

## Run locally
1. Clone the repo: `git clone https://github.com/bala1868/triptrail.git`
2. Open `index.html` in your browser.
